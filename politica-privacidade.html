Política de Privacidade

Saiba como funciona esta demonstração de site e seus links de contato.

Sobre este website

Esta versão estática foi preparada como projeto de apresentação. Não possui banco de dados nem área de login. Não há coleta ou armazenamento de informações pessoais pelo código do site.

Formulário de contato

O formulário desta versão abre o aplicativo de e-mail instalado pelo visitante, com os campos já preenchidos. Nenhum dado é enviado para servidores próprios pelo website.

Links externos

Links para mapas ou outros serviços podem ter práticas independentes de privacidade. Consulte as políticas desses serviços ao acessá-los.

Atualizações

Antes de publicar, revise esta política segundo a infraestrutura definitiva, ferramentas de analytics, hospedagem e integrações efetivamente utilizadas.
